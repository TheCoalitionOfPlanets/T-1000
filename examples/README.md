# English reference voice

`reference-en.wav` is a public reference clip from [Seed-TTS-Eval mini](https://huggingface.co/datasets/zhaochenyang20/seed-tts-eval-mini/resolve/main/en/prompt-wavs/common_voice_en_10119832.wav), originally named `common_voice_en_10119832.wav`.

Transcript: “We asked over twenty different people, and they all said it was his.”

This clip is provided as an example for the local cloning demo. Replace it in the interface with your own recording and the matching transcript to test a different voice.
